Blog Translator

From Foundry

Copies Blogger posts to a destination blog in another language, keeping format, images, videos, tags, date, and location—saved as drafts. Picks up new posts automatically, or backfills a date range. A local app you download. Your Google and LLM keys stay on your machine. Node is bundled.

First open
  1. Mac: Unzip, then drag Blog Translator.app to Applications. If blocked: System Settings → Privacy & Security → Open Anyway.
  2. Windows: Unzip if needed, move the whole folder out of Downloads (Desktop is fine), keep it together, double‑click Blog Translator.cmd. If SmartScreen warns: More info → Run anyway.
  3. Connect Google and paste your LLM API key in the setup wizard.

Unsigned on purpose for now (no Apple notarization / no Windows code signing). Gatekeeper and SmartScreen prompts are normal. Mac notes · Windows notes
